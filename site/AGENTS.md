# AGENTS.md: site/ (the website)

These rules add to the root [AGENTS.md](../AGENTS.md); read that first.

The project website: a landing page, the thinking behind Einsora, the licence, and every document in
the repository, rendered with [Astro Starlight](https://starlight.astro.build). Published to GitHub
Pages by `.github/workflows/site.yml`.

## Layout

```
site/
  site.config.mjs          where the site is published (SITE_URL, BASE_PATH) and the repository URL
  astro.config.mjs         Starlight: title, sidebar, theme
  scripts/sync-docs.mjs    builds pages from the repository's Markdown (run by dev and build)
  src/content/docs/        index.mdx (landing), why.mdx, license.mdx: written here
                           everything else: generated by sync-docs.mjs, gitignored
  src/components/          MarkdownContent.astro draws Mermaid diagrams in the browser
  src/styles/custom.css    colours and small layout rules
  src/assets/logo.svg      the logo (public/favicon.svg is a copy)
```

## Rules

- **The repository is the single source of truth.** Never copy a document into `src/content/docs/`:
  add it to the page list in `scripts/sync-docs.mjs`. Generated pages are gitignored, and their "Edit
  page" link opens the source file.
- **Broken links fail the build.** `sync-docs.mjs` rewrites relative links (to a site page, or else to
  the file on GitHub) and exits non-zero on a link to nothing. Fix the source document, never the
  generated page.
- **Say only what's true.** The landing page and `why.mdx` make claims about what's built: check them
  against `docs/roadmap.md` and the ADRs, and update them in the same change as the roadmap.
- **No money anywhere** (rule 12): no pricing, sign-up, or paid-tier language.
- **No third-party trackers or scripts from other sites.** Every script is bundled from `package.json`.
- Internal links in the hand-written pages are relative (`why/`, `../decisions/…/`), so they work under
  any `BASE_PATH`.

## Commands

```bash
make site-dev      # from the repository root: http://localhost:4321/Einsora/
make site          # build into site/dist; fails on a broken link
```
